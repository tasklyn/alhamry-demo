# إجراءاتُ الرصد — أين تُخزَّن ومتى تُعاد

> أنشأته **جولة ٢٣٤** تنفيذاً لمعيار ٢٣٣: «حين تصف إجراءً، اكتب أين يُخزَّن ومتى يُعاد — وإلّا فقد وصفتَ ولم تُنشئ».
>
> **الحالُ قبله، مقيسة:** كلُّ أدوات الرصد كانت في مجلّد عملٍ مؤقّت (**٤١٩ ملفّاً**) لا يُحفَظ ولا يُدفَع؛ **والمستودعُ لا يحمل سطراً واحداً منها**. فكلُّ إجراءٍ وُصف في التقارير كان يعيش في وصفه فقط.

## ١. المُحقِّق — عرضٌ ونظافةُ تشغيل

**متى يُعاد:** بعد كلّ تعديلٍ على `agents.html`، قبل النشر.
**أيُّ نسخة:** **الموسَّع** عند تغييرٍ في السلوك أو الوسم · **الضيّق** عند إضافة نصوصٍ فقط (`BENCH`/`GATES_ACTIVE`). **ويُذكَر في التقرير أيُّهما شُغِّل** (قاعدةُ جولة ٢٣١).
**ما يفحصه:** أخطاءُ الكونسول · التجاوزُ الأفقي (`scrollWidth − clientWidth`) · وجودُ علاماتِ نصّ الجولة.

```js
// الموسَّع: ٨ حالاتٍ × ٣ عروض = ٢٤. (جولة ٢٣١ — وقبلها كان يفحص الحالةَ الافتراضيةَ وحدَها)
import {chromium} from '/opt/node22/lib/node_modules/playwright/index.mjs';
const b = await chromium.launch();
const states = [
  ['حقيقية · افتراضي', async p=>{}],
  ['عرض',              async p=>{await p.evaluate(()=>useDemo());}],
  ['عرض + منطقة',      async p=>{await p.evaluate(()=>{useDemo();state.region='RUH';render();});}],
  ['عرض + مدى ٩٠',     async p=>{await p.evaluate(()=>{useDemo();state.range=90;render();});}],
  ['عرض + المبيعات',   async p=>{await p.evaluate(()=>{useDemo();state.metric='sales';render();});}],
  ['عرض + جدول',       async p=>{await p.evaluate(()=>{useDemo();state.tbl=true;render();});}],
  ['عرض + تبويب المتجر',async p=>{await p.evaluate(()=>{useDemo();state.product='P-140';state.tab='store';render();});}],
  ['عرض + مسحُ الشريحة',async p=>{await p.evaluate(()=>{useDemo();state.product=null;render();});}],
];
let bad = 0;
for (const w of [1560, 1100, 420]) for (const [name, act] of states) {
  const p = await b.newPage({viewport:{width:w, height:900}});
  const errs = []; p.on('console', m=>{if(m.type()==='error') errs.push(m.text())});
  p.on('pageerror', e=>errs.push(String(e)));
  await p.goto('file:///home/user/alhamry-demo/agents.html'); await p.waitForTimeout(450);
  await act(p); await p.waitForTimeout(450);
  const ov = await p.evaluate(()=>document.documentElement.scrollWidth - document.documentElement.clientWidth);
  if (ov !== 0 || errs.length) { bad++; console.log('✗', w, name, 'ov='+ov, 'errs='+errs.length); }
  await p.close();
}
console.log(bad === 0 ? 'كلُّ الحالات نظيفة' : 'فاشلة: ' + bad);
await b.close();
```

## ١ب. قراءةُ تاريخٍ من مسار العنوان حين تُحجَب الصفحة

**متى يُستعمَل:** حين يظهر خبرٌ أو صفحةٌ رسميةٌ في نتائج البحث **والجلبُ محجوب**، ودعوى اللوحة بلا تاريخ.

**حدُّه المعلَن:** **قرينةٌ لا نصّ** — يُثبِت تاريخَ نشر الصفحة لا مضمونَها، **ويُكتَب في التقرير أنّ الصفحة لم تُفتَح**. ولا يُستعمَل حيث لا يكون النمطُ ظاهراً في المسار.

## ٢. مزامنةُ نسخة الأرتيفكت — نقلٌ ثمّ مقارنةٌ كاملة

**متى يُعاد:** قبل كلّ نشرٍ للأرتيفكت.
**العطبُ الذي عالجه:** جولة ٢٣١ — نقلُ أربعِ كتلٍ بلا فحصِ ما وراءها ترك سطراً متخلّفاً **تسعَ جولاتٍ** في النسخة المنشورة.
**حدُّه المعلَن:** يقارن منطقةَ `<script>` وحدَها — لأنّ نسخة الأرتيفكت تحمل تصميماً مختلفاً عمداً.

```python
import io, difflib
src = io.open(SRC, encoding='utf-8').read()
art = io.open(ART, encoding='utf-8').read()
def blk(t, n):
    i = t.index('const %s = [' % n); j = t.index('\n];', i) + 3; return t[i:j]
for n in ['BENCH', 'GATES_ACTIVE', 'SEASONS_DEMO', 'GATES']:
    new = blk(src, n); old = blk(art, n)
    assert art.count(old) == 1, n
    art = art.replace(old, new, 1)
io.open(ART, 'w', encoding='utf-8').write(art)
def js(t):
    i = t.index('<script>'); j = t.rindex('</script>'); return t[i:j].split('\n')
d = [l for l in difflib.unified_diff(js(src), js(art), lineterm='', n=0)
     if l[:1] in '+-' and l[:3] not in ('+++', '---')]
assert len(d) == 0, d          # التغييرُ خارج الكتل يُنقَل يدوياً ثمّ يُفحَص هنا
```

### ٢أ. ثغرةُ المقارنة — ما لا تراه (جولة ٢٥٢)

**العطبُ المرصود:** المقارنةُ تفحص **منطقة `<script>` وحدَها** بالتصميم. **فحين أُضيف عمودٌ إلى جدولٍ في الجولة ٢٥٢، انتقل مُصيّرُ الصفّ (٨ خانات) ولم ينتقل رأسُ الجدول (٧ عناوين)** — **والمقارنةُ أعطت صفرَ اختلاف وهي صادقة**.

**الفحصُ المضاف — يُشغَّل على الملفّين معاً بعد المزامنة، قبل النشر:**

```js
// لكلّ جدول: عددُ <thead th> = عددُ خانات أوّل صفٍّ في <tbody>
document.querySelectorAll('table').forEach(t => {
  const th = t.querySelectorAll('thead th').length;
  const tr = t.querySelector('tbody tr');
  const td = tr ? tr.children.length : 0;
  if (th && td && th !== td) console.log('✗', t.id || t.className, th, td);
});
```

**ويُشغَّل معه فحصُ التجاوز الأفقيّ وأخطاء الصفحة على نسخة الأرتيفكت نفسِها** — **فهي لم تكن تُفتَح في متصفّحٍ قطّ قبل هذه الجولة، بل تُقارَن نصّاً فقط**.

## ٦. توازنُ السجلّ — قبل إضافة مدخل

**متى يُعاد:** قبل كتابة أيّ مدخلٍ في `BENCH`.

**لماذا:** قِيس في **جولة ٢٣٨** أنّ السجلّ كان قبل هذه النافذة **٧٢ مدخلاً خارجياً مقابل واحدٍ داخليّ**، وأنّ ما أُضيف فيها **٦٩ داخلياً مقابل ٢٧ خارجياً** — **فصار الداخليُّ ٤١٪ من جدولٍ يصف نفسَه بأنّه «كل ثابت سوقي بتاريخ رصده»**.

**متى:** تلقائياً عند كلّ `git commit` — إن وُصل الخطّاف.
**الوصل (يدويٌّ في كلّ نسخةٍ من المستودع):** `git config core.hooksPath .githooks`

**لماذا:** نطق الإنذارُ في **٢٩٤** ثمّ في **٢٩٨** ولم يتغيّر سلوك — **فمقياسٌ ينطق ولا يمنع زينةٌ لا حارس** (معيارُ ٢٩٨).
**حدودُه — تُذكَر ولا تُخفى:** `--no-verify` يتجاوزه (**والتجاوزُ يُذكَر في تقرير الجولة**) · و`core.hooksPath` لا يُنسَخ مع المستودع · ويرث لبسَ «سهل» من ٢٨٠ فعددُه حدٌّ أدنى.

## ٨. عرضُ القاعدة الجديدة على السجلّ — يومَ تُكتَب

**متى:** فورَ كتابة قاعدةٍ جديدة، أو فتحِ بابٍ جديدٍ في قائمة شروط الدليل، أو تعديلِ نصّ قاعدةٍ قائمة.

**الفعل:** يُمسَح `BENCH` و`GATES_ACTIVE` عن **الكلمة المفتاحيّة للقاعدة نفسِها** (لا عن السجلّ كلِّه)، وتُقرأ المطابقاتُ واحدةً واحدة بسؤالٍ واحد: **أفيها ما يخالف القاعدةَ كما كُتبت؟**

**لماذا:** قِيس في **جولة ٣٤٧** أنّ ثلاثةَ اكتشافاتٍ متتاليةٍ (٣٤٣ · ٣٤٥ · ٣٤٦) كانت مخالِفاتٍ **موجودةً في السجلّ قبل أن تُكتَب القاعدةُ التي تخالفها** — ولم تُقرأ مخالِفةً لأنّ أحداً لم يعرضها عليها:

- **«٣٫٩٣× سكّان»** رُصد ووُسم في **٥٨** · وبابُ الاستعمال الذي يسمّيه فُتح في **٣٤٢**.
- **واقعتا سلّة** سُجّلتا في **١٨١** · والقاعدةُ الرابعة كُتبت في **٢٦٨**.
- **`saber.sa`** دخل اللوحةَ في **١٤٧** (مقيسٌ من `git log -S`) · والقاعدةُ الثامنة أُعلنت في **١٧١** ودُوِّنت في مسكن القواعد في **٣٠٢**.

**فالسببُ الغالبُ واحدٌ في ثلاثٍ من ثلاث: القاعدةُ تُكتَب متأخّرةً عن الوقائع، ولا يُعاد عرضُ الوقائع عليها.**

**وأُضيف إليه في ٣٤٩ مُطلِقٌ ثانٍ — <b>عكسُ الأوّل</b>:** **حين يُقيَّد حكمٌ أو يُضيَّق في جولة، يُلحَق القيدُ بنصّ القاعدة <b>يومَها</b>، لا يُترَك في موضع اكتشافه.**
**لماذا:** قِيس في **٣٤٩** أنّ **إحدى عشرةَ قاعدةً من ثلاثَ عشرةَ** كان نصُّها المعروضُ أضيقَ من عملها — **فالقاعدةُ تُكتَب مرّةً وتُقيَّد مراراً، والقيدُ يسكن حيث وُلد.**

**ومُطلِقٌ ثالثٌ أُضيف في ٣٥٢:** **يُفحَص السجلُّ قبل <b>كتابة</b> المعيار لا قبل تنفيذه فقط.**
**لماذا:** قِيس في **٣٥٢** أنّ **ثلاثةً من معايير عشر جولات (٣٤١ · ٣٤٣ · ٣٥٠)** كان جوابُها مصنوعاً كلَّه أو بعضُه — **٣٤١ سبقته ٢٥٨ (إعادةُ قياس أرقام النثر)** · **و٣٤٣ سبقته ٢١٢ (مسحُ ١٣٢ رقماً حرفيّاً في مواضع القرار)** · **و٣٥٠ سبقته ٢٠٨**.
**وحدُّ الأثر مقيسٌ كذلك:** **الثلاثةُ كلُّها <b>مسوحٌ داخليّة</b>، ولم يقع التكرارُ في معيارٍ خارجيٍّ واحد** — **فالتكرارُ خطرُ الأسئلة التي تُسأل عن اللوحة نفسِها، لأنّها كبيرةٌ وقديمة**.

**ومُطلِقٌ رابعٌ أُضيف في ٣٥٦ — <b>وهو أوّلُ مُطلِقٍ يُنفَّذ بأداةٍ لا بفقرة</b>:** **كلُّ دعوى «لم يُجرَّب قطّ» أو «لأوّل مرّة» تُعرَض على السجلّ قبل أن تُكتَب.**
**لماذا:** كُتب في **٣٥٥** أنّ البندَ العاشر (رمزُ الواتساب) «مذكورٌ منذ ٢١٩ ولم يُصوَّب إليه استعلامٌ قطّ» — **والسجلُّ يحمل جولةَ ٢٥٣ بعنوان «الإسنادُ الخارجيّ — لأوّل مرّة» عن البند نفسِه.** **فالدعوى خطأ، والترتيبُ المبنيُّ عليها خطأ.**

**والمُطلِقاتُ الثلاثةُ الأولى لم تمنعه لسببين مقيسين:**

- **نطاقاً:** كلُّها تسمّي **«قاعدة»** و**«معيار»** و**«حكماً مُقيَّداً»** — **ولا تسمّي دعوى عن السجلّ نفسِه.**
- **وشكلاً:** كلُّها **نصٌّ يُقرَأ**، والنصُّ لا يمنع. **وقد وقع الخطأ بعد وضع الإجراء بثماني جولات.**

**فالفعلُ هذه المرّة أداةٌ لا فقرة: `tools/never-check.mjs`، مربوطةٌ بخطّاف ما قبل الالتزام.**
**ما تفعل:** تقرأ الأسطرَ المضافةَ في `agents.html` و`research/`، فإن ادّعى سطرٌ «قطّ» أو «لأوّل مرّة» استخرجت رموزَه (لاتينيّةً وأرقاماً عربيّةً وهنديّةً)، وفتّشت عنها في نسخة الأساس. **فإن وُجد سطرٌ يحمل الرمزَ نفسَه ومعه علامةُ إسنادٍ خارجيّ — مُنع الالتزام** حتى يُقرأ ذلك السطرُ ويُحكَم عليه.
**واختُبرت رجعيّاً على التزام ٣٥٥ نفسِه:** **نطقت ومنعت، وأظهرت في صدر شواهدها مدخلَ ٢٥٣ بعينه.**
**وحدُّها معلَن:** **تستثني السطرَ الحاملَ ⚠، وتستثني الدعوى الواقعةَ بين «…» لأنّ النقلَ ليس ادّعاءً — وهما ثغرتان تُمرَّر بهما دعوى كاذبةٌ بوسمٍ أو بقوسين** · **وتطابق بالرمز لا بالمعنى** · **وتُتجاوَز بـ`--no-verify`، والتجاوزُ يُذكَر.**

**حدُّ الإجراء — يُذكَر ولا يُخفى:** **المسحُ بالكلمة المفتاحيّة يفوته ما صيغ بألفاظٍ أخرى** · **والقراءةُ حكمٌ لا قياس** · **ولا يُغني عن اختبارِ القاعدة على مخالفٍ يُطلَب خارجاً (٣٤٤ · ٣٤٥ · ٣٤٦).**

## ٩. حدُّ هذا الملفّ

**يصف ثمانيةَ إجراءاتٍ يعملُ بها الراصدُ اليوم.** **ولا يزعم أنّها كلُّ ما يُفعَل** — بعضُ الخطوات ما زالت في الرأس، وستُضاف حين تُوصَف.
**وموضعُ أكثرِ الأدوات ما زال مجلّدَ عملٍ مؤقّتاً** — **والمحفوظُ هنا نصُّها لا ملفّاتُها.** **والاستثناءُ أداتان تسكنان المستودعَ نفسَه:** **`tools/drift-check.mjs` (٢٩٩)** · **و`tools/never-check.mjs` (٣٥٦)** — **وكلتاهما مربوطةٌ بخطّاف `.githooks/pre-commit`.**
